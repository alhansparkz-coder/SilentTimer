# Silent Timer (Android widget)

One tap on the widget -> choose Vibrate or Silent and a time (15 / 20 / 30 min, 1 h, 2 h).
When the time is up, your previous sound mode is restored automatically.

## Build and install
1. Install Android Studio (developer.android.com/studio).
2. File > Open, choose this SilentTimer folder, wait for Gradle sync to finish.
   (If Studio offers to upgrade the Android Gradle Plugin, accept it.)
3. On your phone: Settings > About phone > tap "Build number" 7 times, then
   Settings > Developer options > turn on USB debugging. Connect it with a USB cable.
4. Press the green Run button in Android Studio.
   Or: Build > Build APK(s), copy the APK to your phone, open it to install.

## First run on the phone
1. Open "Silent Timer", tap "Allow Do Not Disturb access" and switch it on for the app.
2. Touch and hold the home screen > Widgets > Silent Timer > drag it out.
3. Tap the widget to start a timer. Tap it again while a timer runs to restore sound early.

If you change the sound mode yourself during a timer, the app leaves your choice alone.
